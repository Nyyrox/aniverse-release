## 1.1.8 - 2026-08-03

### Added

- Download support for more stream types, including direct, dubbed, language, and native stream sources where available.
- Background download progress handling with downloaded episodes accessible from the library/offline playback area.
- Details page improvements with studios, aired dates, episode duration, source type, related anime cards, inline trailers, and skeleton loading.

### Improved

- Hero banner swipes, episode card reveals, provider panels, and page transitions use smoother spring-style motion.
- Downloaded episodes show clearer progress, file size, and quick play actions.
- Better app flow for users who want to watch anime online and save episodes for offline playback.

## 1.1.7 - 2026-08-01

- Season tabs in the player for multi-season anime like Demon Slayer, Attack on Titan, Jujutsu Kaisen, and similar shows.

### Improved

- Player UI refreshed with cleaner provider/source panels, autoplay countdown, and smoother fullscreen handling.
- Details page now handles AniList disambiguation with visible choices instead of silent failure.
- Browse page improved with TV channel and OTT platform chips.
- Subtitle panel now sorts English first, shows better labels, and fixes single-select behavior.
- Profile streak rewards and animated profile visuals refined.

### Fixed

- Updated Videasy domain handling.
- Season resolution no longer flattens multi-season anime into confusing episode counts.
- Subtitle providers receive IMDb IDs more reliably from AniList external links.
- Community avatar frames and animated usernames render correctly.
- Watch button on details page navigates even if AniList resolution times out.
